# OKme! — オフィス向けAI Companion（Webデモ）

ARメガネの視界の中に AI アシスタント「OKme!」が表示されているような体験を、
ブラウザだけで再現するプレゼン用デモサイトです。実機のARメガネや
本物の疲労測定は使用していません（コンディション値などはデモ用のランダム表示）。

## 技術スタック

- React 19 / Next.js 16 (App Router)
- Tailwind CSS v4
- カメラ起動: `navigator.mediaDevices.getUserMedia`

## 起動方法

```bash
cd okme-demo
npm install      # 初回のみ
npm run dev      # http://localhost:3100
```

本番ビルド:

```bash
npm run build && npm run start
```

## ページ構成

- `/` … トップページ（ロゴ / キャッチコピー / キャラクター / デモ開始ボタン / 機能紹介）
- `/demo` … ARメガネ体験デモ
  - 左: センサー状態カード（位置情報・歩数・カレンダー・心拍数）
  - 中央: カメラ映像 + AR風オーバーレイ（時刻 / 天気 / 予定 / 次の予定 / コンディション / キャラクター吹き出し）
  - 右: AIチャット（モック応答）

## カメラについて

中央エリアの「カメラを起動」を押すと `getUserMedia` でカメラを使用します。
許可が無い・非対応の場合は、オフィス／街並み風のダミー背景を表示します。
カメラ映像はブラウザ内でのみ扱い、外部送信は行いません。

## 画像アセット

`public/images/` に以下を配置すると差し替わります（未配置でも
インラインSVGのプレースホルダーへ自動フォールバックします）。

- `okme-logo.png`
- `okme-character.png`
- `okme-hero.png`

## デザイン

白 / ライトブルー / ネイビー / オレンジ基調、角丸とグラスモーフィズムを
多用した「やさしく未来感のある」ビジネス向けデザイン。レスポンシブ対応。
