# OKme! 画像アセット

このフォルダには本番用の画像を配置します。アプリは以下のファイル名を参照します。

- `okme-logo.png` … OKme! ロゴ画像
- `okme-character.png` … OKme! キャラクター画像
- `okme-hero.png` … ARメガネ＋キャラクターのメインビジュアル

> これらの `.png` がまだ無い場合でも、アプリ内のコンポーネント
> (`src/components/brand.tsx` の `OkmeImage`) が
> 自動でインラインSVGのプレースホルダーにフォールバックするため、
> 画面は崩れません。本番画像が用意できたら、上記ファイル名で
> このフォルダに置くだけで差し替わります。

参考用に同名の `.svg` プレースホルダーも同梱しています。
